# Changelog

## 1.0.0 - 2026-10-15

First release.

- The `=` key and the `fsrstatus` console command show whether FSR is actually upscaling and apply the preset from `config.txt`.
- Recovers FSR when the game silently renders at native resolution, including after alt-tabbing out of DX11 exclusive fullscreen.
- Tested in game with UE4SS v3.0.1 Beta.
